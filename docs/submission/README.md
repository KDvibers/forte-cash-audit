# Пакет сдачи и совместная проверка — этап 10

Касымбек отвечает за интерфейс и сервер приложения, Данияр — за анализатор,
правила и доказательства. Этот пакет связывает подготовленные части проекта
с требованиями сдачи кейса ForteBank.

**Состояние на 17 октября 2026 года: пакет подготовлен, финальная сдача ещё
не готова.** Приложение проверено в `mock`; `analyzer/service.py` отсутствует
в текущем коде. По сообщению Данияра, его работа находится на проверке
последовательностей кадров. Реальный анализ, его точность и полный срок
обработки пока не подтверждены.

## Где хранить заполненные материалы

В Git остаются только инструкции и пустые шаблоны. Имена исходных видео,
разметку, подробные результаты и кадры храните в исключённых локальных
каталогах. Ключ API передаётся отдельно закрытым способом и не вставляется
даже в заполненный текст отчёта.

Из корня репозитория в PowerShell создайте новый каталог для заполнения:

```powershell
$packetName = 'draft-' + [Guid]::NewGuid().ToString('N')
$packetDir = Join-Path (Get-Location).Path ('backend\.local\submission\' + $packetName)
New-Item -ItemType Directory -Path $packetDir -ErrorAction Stop | Out-Null
Copy-Item -LiteralPath '.\docs\submission\JURY_HANDOFF.template.md' -Destination (Join-Path $packetDir 'JURY_HANDOFF.md')
Copy-Item -LiteralPath '.\docs\submission\MEASUREMENTS.template.md' -Destination (Join-Path $packetDir 'MEASUREMENTS.md')
Write-Output $packetDir
```

Каждый запуск создаёт новую папку и не заменяет заполненные материалы.
Ссылки на инструкции и примеры команд открывайте в исходном репозитории;
пустой шаблон сам по себе не является готовым пакетом для отправки.

## Что уже проверено и что предстоит

Результаты этапа 9 зафиксированы в [руководстве внешнего доступа](../PUBLIC_ACCESS.md):
193 backend-теста, 44 frontend-теста, внешний HTTPS, API, браузерные маршруты
и передача синтетического MOV размером 29 000 000 байт. Эти проверки относятся
к инфраструктуре и тестовому анализатору. На этапе 10 код приложения не меняется,
и эти числа не выдаются за новый прогон или проверку модели.

Обязательные следующие подтверждения: настоящий результат в `real`, связь
правила с наблюдаемым событием, реальные кадры с точным временем, измеренный
полный цикл, доступ с другого устройства и воспроизводимый запуск на ноутбуке
Данияра. Пока они не получены, соответствующие поля остаются незаполненными.
