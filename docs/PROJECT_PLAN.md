# План готового продукта

Цель — готовый сервис ForteBank для новых видео и удалённой проверки жюри. Пользователь загружает видео и без ручного запуска кода получает результат, события, время, настоящие кадры и обоснованные нормативные ссылки. Проверяются ранее не показанные записи и другой ракурс. Один работающий сигнал остаётся промежуточным результатом.

Используем следующие семь этапов. Нумерацию сохраняем; исторические номера экспериментов и отдельные планы компонентов её не заменяют. Готовность подтверждаем проверками, отдельно указывая реализованный код, проверенные возможности и оставшуюся работу.

## 5. Добавить проверенные правила и доказательства

**Статус:** выполнен частично; цепочка полностью связана только для одного условного сигнала.

Остаётся:

- Расширить набор обоснованных проверок по наблюдаемым сценариям и открытым источникам РК.

Условие завершения: для заявленных типов подтверждены наблюдаемая цепочка, применимость источника, классификация, время и доказательства. Обнаружение любого неизвестного нарушения и идеальная точность заранее не гарантируются.
