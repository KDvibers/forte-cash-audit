# Интерфейс — этап 3

Статический интерфейс Forte Cash Audit в стиле референса: светлый фон,
фиолетовые акценты, округлые карточки и короткий путь к выбору видео.
Он работает без установки пакетов и без сборки.

## Запуск

Из корня репозитория выполните в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\frontend\preview.ps1
```

Откройте <http://127.0.0.1:4173>. Чтобы остановить просмотр, нажмите `Ctrl+C`
в окне сервера. Сервер API для этого этапа запускать не требуется.

## Что можно проверить

- Выбор одного MOV через кнопку или перетаскивание в область загрузки.
- Показ имени и размера выбранного файла, его замену и удаление из выбора.
- Сообщения для неподходящего расширения, пустого файла, нескольких файлов
  и размера больше 100 МиБ (104 857 600 байт).
- Сохранение уже выбранного видео при ошибке в новом файле или отмене выбора.
- Окно справки, навигацию с клавиатуры и отображение на узком экране.

Расширение `.mov` проверяется без учёта регистра. На этом этапе браузер
проверяет только имя и размер файла; фактический формат видео проверяет
сервер после подключения API.

## Границы этапа

Файл остаётся в памяти текущей страницы. Интерфейс не отправляет видео на
сервер, не хранит API-ключ и не запускает анализ. После обновления страницы
выбор сбрасывается. Экран не выдаёт тестовый результат за реальную проверку.

Подключение к API относится к этапу 4. После него можно будет показывать
состояние обработки и переходить к результату без отдельной кнопки «Ответ».
Экран подробных результатов относится к этапу 5.

## Файлы

- `index.html` — структура страницы и тексты.
- `styles.css` — оформление и адаптация к разным размерам экрана.
- `app.js` — выбор файла, проверки, перетаскивание и окно справки.
- `preview.ps1` — локальный сервер для просмотра интерфейса.

В `app.js` нет сетевых запросов, хранилища браузера или подключения внешних
библиотек.
