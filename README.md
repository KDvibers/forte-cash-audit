# Forte Cash Audit

Локальная проверка видео кассовых операций для хакатона ForteBank.

## Запуск интерфейса и API — этап 4

Из корня репозитория, в PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\backend\start.ps1 -Mode mock
```

Откройте <http://127.0.0.1:8000>. Выберите или перетащите MOV: файл автоматически
отправится на сервер, после чего появятся состояние проверки и итоговое заключение.
Интерфейс и API работают в одном процессе, отдельный сервер frontend не нужен.

- [Интерфейс, сценарии проверки и ограничения](frontend/README.md).
- [Сервер, публичный API и подключение анализатора](backend/README.md).

Для первого запуска добавьте `-Install`; рекомендуется Python 3.12. Frontend
не требует Node.js или сборки. Остановка сервера — `Ctrl+C`.

**Режим `mock` возвращает синтетические ответы и не анализирует содержимое видео.**
После добавления модуля анализатора запускайте с `-Mode real`. Автоматической
подмены реального анализа тестовым нет. Без параметра выбран режим `real`.

На этапе 4 выводятся общий результат и число событий. Подробный просмотр событий,
таймкодов и кадров относится к этапу 5.
